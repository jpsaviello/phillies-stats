# Schedule Page Betting Odds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add DraftKings moneyline and run line odds as a second line on each upcoming game row in the Schedule tab, fetched from The Odds API with 30-minute localStorage caching.

**Architecture:** A single `fetchOdds()` call in `src/api/mlb.ts` fetches all upcoming MLB games from The Odds API and caches the result in `localStorage` for 30 minutes. `Schedule.tsx` fires `fetchOdds()` in parallel with `fetchSchedule()`, matches games by team name pair, and renders a second line with ML and RL odds beneath the opponent name for upcoming games only. Odds failures are caught silently so the schedule always renders.

**Tech Stack:** React 19, TypeScript, Vite, The Odds API v4, localStorage

## Global Constraints

- No test runner is configured -- verification is done by running the app and inspecting the UI
- API key stored in `.env.local` as `VITE_ODDS_API_KEY` (covered by `*.local` in `.gitignore`)
- Bookmaker: DraftKings only (`bookmakers=draftkings`)
- Markets: moneyline (`h2h`) and run line (`spreads`) only
- Phillies team name as returned by The Odds API: `"Philadelphia Phillies"`
- Tailwind v4 (CSS-first, no `tailwind.config.js`)
- Phillies red: `text-[#E81828]` / `bg-[#E81828]`

- [ ] **Step 3: Add fetchOdds with localStorage caching**

Add after `formatOdds`:

```ts
const ODDS_CACHE_KEY = 'phillies_odds_cache'
const ODDS_CACHE_TTL = 30 * 60 * 1000

export async function fetchOdds(): Promise<OddsGame[]> {
  const raw = localStorage.getItem(ODDS_CACHE_KEY)
  if (raw) {
    const cached: { timestamp: number; data: OddsGame[] } = JSON.parse(raw)
    if (Date.now() - cached.timestamp < ODDS_CACHE_TTL) return cached.data
  }
  const key = import.meta.env.VITE_ODDS_API_KEY as string
  const url =
    `https://api.the-odds-api.com/v4/sports/baseball_mlb/odds/` +
    `?apiKey=${key}&regions=us&markets=h2h,spreads&bookmakers=draftkings`
  const res = await fetch(url)
  if (!res.ok) throw new Error(`Odds API ${res.status}`)
  const data: OddsGame[] = await res.json()
  localStorage.setItem(ODDS_CACHE_KEY, JSON.stringify({ timestamp: Date.now(), data }))
  return data
}
```

- [ ] **Step 4: Add getPhilliesOdds helper**

Add this function outside the `Schedule` component (place it just above the `export default function Schedule()` line):

```ts
function getPhilliesOdds(oddsGame: OddsGame) {
  const dk = oddsGame.bookmakers[0]
  if (!dk) return null
  const h2h = dk.markets.find(m => m.key === 'h2h')
  const spreads = dk.markets.find(m => m.key === 'spreads')
  const ml = h2h?.outcomes.find(o => o.name === 'Philadelphia Phillies')?.price
  const rl = spreads?.outcomes.find(o => o.name === 'Philadelphia Phillies')
  if (ml === undefined || !rl) return null
  return { ml, rlPoint: rl.point ?? -1.5, rlJuice: rl.price }
}
```
