# Chat Bot Implementation Plan

> Spec: docs/superpowers/specs/2026-07-21-chat-bot-design.md
> Execution mode: multi-agent (implementation subagent, separate review + webapp-testing agents; fixes routed back via SendMessage)

**Goal:** Floating Claude-powered chat widget answering Phillies questions via `POST /api/chat` with server-side MLB Stats API tool use.

**Architecture:** Hono route in `server/` runs the `@anthropic-ai/sdk` beta tool runner (`claude-opus-4-8`); React widget mounted once in `App.tsx` keeps text-only history.

**Tech stack:** Hono + @anthropic-ai/sdk (server, ESM/NodeNext), React 19 + Tailwind v4 tokens (client).

## Global Constraints

- No sampling params (`temperature`/`top_p`/`top_k`) — Opus 4.8 rejects them with 400.
- `phillies-*` Tailwind tokens only, no inline hex.
- No git add/commit/push — user handles git.
- `npm run lint`, `npm run build`, `npm --prefix server run build` must pass after every task.

### Task 1: Backend `/api/chat`

**Files:** `server/src/chat.ts` (new), `server/src/index.ts`, `server/package.json`

- [ ] Install `@anthropic-ai/sdk` in `server/`
- [ ] `chat.ts`: request validation (roles, ≤20 messages, ≤2000 chars each, last message user), 503 keyless, 502 on upstream failure

- [ ] Tool runner: `claude-opus-4-8`, `max_tokens: 4096`, adaptive thinking, `effort: "low"`, `max_iterations: 8`, dated system prompt
